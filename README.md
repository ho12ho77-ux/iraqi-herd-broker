# Iraqi Herd Broker

ممتاز! الآن وصلنا للمكان الصحيح. 👏

في مربع الدردشة داخل Lovable، انسخ النص التالي وأرسله:

أريد إنشاء منصة إلكترونية احترافية باسم علوة الساقي للمواشي، تعمل في العراق، وتربط البائعين والمشترين من خلال نظام وساطة سرية، دون كشف بيانات البائع للمشتري أو العكس.

أريد واجهة عربية بالكامل من اليمين إلى اليسار، وتصميماً احترافياً مناسباً لسوق المواشي.

تتضمن المنصة:

تسجيل حسابات البائعين والمشترين.

اختيار المحافظة والمدينة والقضاء.

عرض المواشي مع الصور والأوزان والأسعار.

تقديم عروض شراء سرية والتفاوض.

ضمان جدية المشتري بنسبة 2.5% وفق شروط واضحة.

لوحة تحكم إدارية.

صلاحيات منفصلة للمدراء والموظفين.

حساب Super Admin للمدير الأعلى، بصلاحيات كاملة.

نظام توثيق الحسابات وحماية البيانات.

إدارة الصفقات والشكاوى والنقل والتسليم.

ابدأ ببناء النسخة الأولى، واعرض لي تصميم المنصة قبل إضافة أي نظام دفع حقيقي أو بيانات حساسة.
